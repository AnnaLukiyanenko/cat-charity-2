# О проекте
QRKot — благотворительный фонд помощи котам.

Это REST API для управления благотворительными проектами и пожертвованиями.

Фонд создаёт проекты для сбора средств на помощь котам и котятам. Пользователи могут создавать пожертвования, которые автоматически распределяются между открытыми проектами.

## Возможности

создание благотворительных проектов;
просмотр всех благотворительных проектов;
редактирование открытых проектов;
удаление проектов, в которые ещё не поступали средства;
создание пожертвований;
просмотр пожертвований;
автоматическое распределение пожертвований между проектами;
распределение средств по принципу FIFO — сначала финансируются самые старые открытые проекты;
автоматическое закрытие проекта после полного сбора необходимой суммы;
автоматическое распределение свободных пожертвований при появлении нового проекта;
валидация входных данных;
регистрация и аутентификация пользователей;
разграничение доступа для обычных пользователей и суперпользователей.

## Установка

Перейдите в директорию проекта:
cd cat-charity-2

Создайте виртуальное окружение:
python3 -m venv venv

Активируйте его:
source venv/bin/activate

Установите зависимости:
pip install -r requirements.txt

Создайте файл .env в корневой директории проекта:
```env
DATABASE_URL=sqlite+aiosqlite:///./qrkot.db
SECRET=ваш_секретный_ключ

Применение миграций
alembic upgrade head

Запуск приложения
uvicorn app.main:app --reload
